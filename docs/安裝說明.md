# 呼叫瓦庫：安裝說明

《殺戮尖塔 2》的遊戲內 AI 助手。面板在畫面右上角，可以只給建議、幫你選路線或選牌、接手一場戰鬥或整局。

AI 用的是**你自己的訂閱帳號**（Claude、ChatGPT 或 Google），會消耗你自己的額度。

## 1. 需要準備

- Windows 版《殺戮尖塔 2》（Steam）。
- **Python 3.12**：到 <https://www.python.org/downloads/> 下載安裝。不需要額外安裝套件。
- **至少一個 AI 命令列工具**，並用自己的帳號登入（下一節）。

## 2. 安裝 AI 工具（擇一或多個）

| 工具 | 需要的訂閱 | 安裝方式 |
|---|---|---|
| Claude Code | Claude Pro／Max | 依 Anthropic 官方說明安裝 Claude Code（<https://claude.com/claude-code>） |
| Codex CLI | ChatGPT Plus／Pro | 依 OpenAI 官方說明安裝 Codex CLI |
| Antigravity CLI（Gemini） | Google AI Plus／Pro | 在 PowerShell 執行 `irm https://antigravity.google/cli/install.ps1 \| iex` |

裝好後**不用自己開終端機登入**：進遊戲後，面板會偵測已安裝的工具；選了還沒登入的模型時，會出現「登入 Claude／Codex／Gemini」按鈕，按下去會打開官方的登入流程。

## 3. 安裝模組

1. 下載 `vakuu-mod-版本.zip`。
2. 找到遊戲資料夾：Steam 收藏庫 → 右鍵《殺戮尖塔 2》→ 管理 → 瀏覽本機檔案。
3. 打開裡面的 `mods` 資料夾（沒有就自己建一個）。
4. 把 zip **整個解壓縮到 `mods` 裡**。完成後應該是：
   ```
   mods/
     STS2_MCP.dll
     STS2_MCP.json
     vakuu/
       vakuu_engine.py
       ...
   ```
5. 啟動遊戲（如果 Steam 問，選 **Play with Mods**）。右上角出現「呼叫瓦庫」就成功了。

## 4. 使用

| 按鈕 | 做什麼 |
|---|---|
| 只給建議 | 看目前畫面給建議，不操作遊戲 |
| 幫我選 | 只處理眼前這一步（選路線、選牌、商店、事件、打這回合） |
| 接手這場戰鬥 | 打到這場戰鬥結束，停在獎勵畫面 |
| 接手整局 | 一直打到結束或遇到需要人處理的畫面 |
| 停止 | 隨時收回控制權 |

- **模型**：上面的選單選模型，「思考強度」選低／中／高。省額度建議「Claude · 自動調度」（平常用 Haiku，難的才用 Sonnet）或「Gemini · 3.8 Flash」配低。
- **額度**：面板會顯示 Claude、Codex 的剩餘額度；Gemini 的額度要在終端機執行 `agy`，輸入 `/usage` 查看。Google AI Plus 的額度大約只夠接手幾十步，Pro 比較多。
- 接手時請不要操作遊戲；想自己來就按「停止」。

## 5. 常見問題

- **沒有出現「呼叫瓦庫」**：確認是用 Play with Mods 啟動、`vakuu` 資料夾跟 `STS2_MCP.dll` 在同一層，並且已安裝 Python 3。
- **面板說「還沒安裝某工具」**：照第 2 節安裝那個工具，或在選單改選其他模型。
- **設定與記錄存在哪**：遊戲資料夾不能寫入時，存在 `%LOCALAPPDATA%\vakuu`。刪掉這個資料夾即可重設。
- **移除**：刪掉 `mods` 裡的 `STS2_MCP.dll`、`STS2_MCP.json` 和 `vakuu` 資料夾。

## 6. 注意事項

- vakuu 只透過本機的遊戲 API 讀取和操作遊戲，不會修改存檔；但遊戲更新後可能需要等模組更新。
- 用訂閱方案驅動自動化工具，請自行確認各服務（Anthropic、OpenAI、Google）的使用條款。
