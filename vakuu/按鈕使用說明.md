# 呼叫瓦庫：使用說明

## 瓦庫角色文案

接手會在敵方回合或戰鬥動畫期間自動等待，回到出牌階段後繼續；等待不呼叫模型、不計入操作步數。超過 45 秒未回到可操作畫面會停止並提示；仍可隨時按「停止」。

待命、思考、接手和停止使用瓦庫「第一個惡魔」的契約與誘惑口吻。模型建議先給一句短的原創角色台詞，再以「建議：」說明實際操作和戰術理由；Codex 與 Claude 都採用相同設定。角色語氣不改變操作規則，不故意亂打或捏造遊戲效果。錯誤原因與操作進度仍明確顯示。

## 遊戲內面板（目前已安裝）

面板顯示所選服務的額度資訊。Codex 使用官方 app-server 的 account/rateLimits/read 讀取剩餘百分比與重置時間（台灣時間），快取一分鐘；額度屬於帳號共用窗口，不能推算剩餘可呼叫次數。Claude 讀取 Claude Code 本機登入憑證，查詢官方使用量（與 /usage 相同來源），顯示 5 小時與 7 天窗口的剩餘百分比與重置時間，同樣快取一分鐘；不更新或改寫憑證，憑證過期時提示先完成一次 Claude 呼叫。不以本機 Token 數推算。額度查詢不呼叫模型。

卡牌獎勵與商店的卡牌評分來自 Spire Codex 公開 API：依目前角色，取進階10以上社群對局的勝率分數（Codex Score），每天最多更新一次並存在本機；無法連線時沿用上次的資料，從未取得過資料時不提供評分。

「登入 Claude」平常隱藏。選擇 Claude 模型、展開面板或完成呼叫時，程式只讀取 Claude Code 登入狀態；確認尚未登入才顯示按鈕。完成登入後重新展開面板即可更新狀態；選擇 Codex 不顯示此按鈕。登入檢查不呼叫模型，不返回帳號或授權資料。

右上角的「呼叫瓦庫」按鈕可展開或收合面板，內含模型選單、思考強度與下列按鈕。回覆直接顯示在遊戲內。

| 按鈕 | 做什麼 |
|---|---|
| 只給建議 | 看目前畫面給建議，不操作遊戲 |
| 幫我選 | 只處理眼前這一步，做完就交還。文字依畫面而變：地圖「幫我畫路線」（畫好的路線會保留，之後在地圖上再按會照路線走、不必再問模型）、戰鬥「幫我打這回合」、選牌「幫我選牌」、商店「幫我逛商店」（含刪牌）、休息點、事件、獎勵 |
| 接手這場戰鬥 | 打到這場戰鬥結束，停在獎勵畫面讓你自己挑；不在戰鬥中時不能按 |
| 接手整局 | 一直打到通關、死亡或遇到需要人處理的畫面 |
| 停止 | 隨時收回控制權 |
面板採深色石板底、古銅邊框與金色文字；按鈕與模型選單使用相同樣式。

模型選單可選 Codex 預設或指定模型，以及 Claude Sonnet 5.5、Opus 5.5、Haiku 5.5。Claude 傳入完整版本 ID，使顯示與請求一致。設定會保存，下一次呼叫生效；處理中不能切換。實際可用模型依帳號授權，若不支援會顯示錯誤，不會自動改用其他服務。更新選單後需正常退出並重開遊戲，載入新版按鈕服務。

Claude 使用本資料夾的 Claude Code 官方程式與 Claude 訂閱登入。桌面版登入不會自動替代 Code 登入；面板的「登入 Claude」會開啟官方登入流程。已驗證 Claude Pro 登入成功、Sonnet 成功讀取遊戲主選單並回傳結構化建議。選 Claude 消耗 Claude 訂閱額度；選 Codex 使用 Codex 額度。沒有另接 API 金鑰。

現有 STS2MCP 模組已擴充面板功能。遊戲啟動時依 STS2_CodexPanel.conf 啟動本機按鈕服務；遊戲退出時停止其子程序。介面嵌在遊戲內，Codex 與評分仍由本機 Python/Codex 程式執行。閒置時不呼叫模型；處理請求時才同步顯示進度。

已驗證：針對 v0.111.0 編譯成功、遊戲內面板建立成功、中文顯示正常、本機按鈕服務啟動並回報狀態。遊戲更新後需要重新確認模組相容性。

已實測遊戲內「只給建議」：於故障機器人 A9 涅奧選擇畫面取得 Codex 建議，回覆成功顯示在遊戲面板，處理完後兩個按鈕重新啟用。未執行選項或改動遊戲進度。

安裝檔案保存在本資料夾：STS2_MCP.dll、STS2_MCP.json、STS2_CodexPanel.conf。設定目前指向本機 Python 與本資料夾的程式，請保留資料夾位置。

## 接手注意事項

- 只有按下按鈕才會讀取局面並呼叫模型；閒置時不呼叫。一次接手可能有多次模型呼叫，按「停止」即可交還控制權，已送入遊戲的動作無法撤回。
- 接手期間請暫停手動操作；若局面在模型思考期間被改變（例如手動出牌），接手會停止以避免操作過時局面。
- 主選單、遊戲結束或不支援的畫面會停下，請手動處理後再呼叫。

保留同資料夾的 Python 程式。呼叫紀錄在 button-runtime/（只保留最近 40 次），包含遊戲決策與模型輸出。
